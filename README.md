# ai-to-qst-assessment-pipeline
"I got tired of Canvas/Moodle question lock-in and paying SaaS fees, so I built these LLM prompts to output qst xml, which can be directly imported into QST (Quiz/Survey/Test), which runs beautifully on a cheap Docker node. And is a self hosted, enterprise, assessment solution"."
The first template will  be for ChatGpt, followed by Gemini and Perplexity.
