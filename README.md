# ai-to-qst-assessment-pipeline
"I got tired of Canvas/Moodle question lock-in and paying SaaS fees, so I built these LLM prompts to output QST XML or QST TEXT, which can be directly imported into QST (Quiz/Survey/Test), which runs beautifully on a cheap Docker node".
QST is a self hosted, complete, full featured, open source, enterprise assessment platform.

The first template will be for ChatGPT, followed by Gemini and Perplexity.
